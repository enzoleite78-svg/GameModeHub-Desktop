GameModeHub é um aplicativo desktop avançado desenvolvido em C# (.NET 8 / WPF), (feito 99% com o google gemini), projetado para centralizar, 
otimizar e dar total liberdade de personalização à sua experiência de jogos no Windows.
Ele oferece desde automação de processos e controle de hardware até uma interface totalmente customizável e
integração móvel via servidor HTTP local.
Ele foi feito pra quem quer otimzar seu tempo quando quer jogar, 
botões customizaveis pra escolher qual monitor voce quer jogar,
se vc tem multiplos monitores vc apenas aperta um botao e so o monitor
principal fica ligado e ja executa o modo steam bigpicture (ou o laucher de sua preferencia),
fecha todos os apps selecionados por vc no memu de configurações automaticamente,
